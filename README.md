# Degree Grade Tracker

A private, browser-based grade tracker configured for Fall 2026 MATH 470, MATH 528, and MATH 620.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html` to the top level of the repository.
3. Commit the upload to the `main` branch.
4. Open the repository's **Settings** page.
5. Select **Pages** in the left sidebar.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and the `/ (root)` folder, then click **Save**.
8. Wait a few minutes and open the URL shown by GitHub Pages.

## Data and privacy

Grades are stored in the browser using `localStorage`; they are not committed to GitHub. Use the tracker's **Export backup** button regularly. Data entered on one browser or device does not automatically appear on another device. Use **Export backup** and **Import backup** to move the data.

## Updating the site

Replace `index.html` in the repository and commit the change. GitHub Pages will redeploy automatically.
